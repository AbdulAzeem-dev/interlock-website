# Wintex image folders

- Army/: military garments and label details (your structure retained).
- sweaters/summer/ and sweaters/winter/: your seasonal styles; g = women, b = men.
- sweaters/cardigans/: additional cardigan references.
- sweaters/editorial/: collection covers and folded knitwear.
- socks/: socks and the collection cover.
- gloves/: cream and striped glove photographs.
- scarves/: scarf photographs.
- uniforms/: school, corporate and institutional garment photographs.
- manufacturing/machines/: Cixing, Shima Seiki and machine references.
- manufacturing/factory/: factory photographs.
- manufacturing/details/: knitting details and the video poster.
- materials/yarn/: yarn photographs.
- materials/textures/: knit and wool textures.
- materials/details/: garment construction close-ups.
- branding/: tag and private-label photography.

Brand logos, woven labels, tags and favicons used by the interface remain in public/brand/. Original supplied brand files remain in assets/.

The website uses explicit image paths. Keep the exact filename when replacing an existing photograph; change the source path if its filename changes. A newly added photograph needs to be added to the appropriate gallery list in src/content/ or src/components/products/FashionCollectionsPage.tsx.

Identical folded-knitwear copies and identical sock-flatlay copies have been consolidated; no unique photograph was discarded.
